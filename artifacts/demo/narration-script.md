# Tiny demo narration script

Target: 90–150s; rendered: 146.2s

## Scenes

### 01. Tiny  -  teacher preview

Tiny is an offline-first teacher tool for rural primary schools. Teachers use the Android phone they already have. Parents use ordinary SMS, and pupils have no account or app.

### 02. Language

Teachers can choose English, Hausa, Yoruba, or Igbo. The non-English interface strings are drafts, and missing text falls back to English until native review.

### 03. Honest preview

This build is deliberately honest. Cloud sync and live SMS are not connected. The preview runs on synthetic data only.

### 04. Home

The home screen shows today's classes, pending sync, parent messages, and the next useful action.

### 05. Classes

A teacher can manage more than one class, view the roster, and add a pupil locally.

### 06. Offline attendance

Attendance works offline. Mark every active pupil, review the register, and submit locally. Only absences create an immediate notification job after server acceptance.

### 07. 5E lessons

A saved 5E lesson opens without internet. It is a teacher-authored scaffold, not a claim of full NERDC coverage.

### 08. Optional AI

AI is optional. On this emulator, Gemini Nano is unavailable, and cloud AI is not configured. Tiny falls back to reviewed teaching strategies that work offline. The core lesson never depends on a model.

### 09. Parent SMS

Parent conversations arrive through the SMS adapter. In this preview the adapter is mocked, so nothing leaves the device.

### 10. Teacher reply

A teacher can reply from Tiny without exposing a personal phone number. Provider acceptance is not the same as delivery.

### 11. Settings

Settings contains language, sync, and privacy controls. The Note 10 plus is a general test device; Gemini Nano needs supported hardware.

### 12. The next gates

Tiny is not finished. The remaining gates are Firebase access, App Distribution, native translation review, and a supported on-device AI device. Big impact. Small requirements. Accessible everywhere.
