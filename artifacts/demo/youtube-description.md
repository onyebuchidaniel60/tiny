**Description:**

Tiny is an offline-first Android teacher tool for rural primary schools in Nigeria. Teachers use the phone they already have; parents use ordinary SMS; pupils have no account or app.

This 146-second preview shows the teacher workflow, mock parent conversations, approved progress, and the Firebase integration: test-phone Auth, Firestore workspace bootstrap, and Firebase AI Logic cloud fallback with the source reported by the SDK. On-device Gemini Nano is requested with `PREFER_ON_DEVICE` but is not claimed on unsupported hardware.

The test build is a synthetic-data preview. No live SMS is sent, no real pupil/guardian data is used, and Cloud Functions remain emulator-only under the Spark/NGN 0 budget.
