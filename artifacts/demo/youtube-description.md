**Description:**

Tiny is an offline-first Android teacher tool for rural primary schools in Nigeria. Teachers use the phone they already have; parents use ordinary SMS; pupils have no account or app.

This 133-second preview shows one canonical synthetic primary school on Android and in the web companion: evidence-backed pupil and class intelligence, attendance, assessments, teacher observations, follow-ups, lessons, mock parent conversations, and Firebase AI Logic with the requested mode, actual SDK source, duration and honest fallback. The SDK-reported source here is Cloud Gemini. On-device Gemini Nano is requested with `PREFER_ON_DEVICE` but is not claimed on unsupported hardware.

The test build is a synthetic-data preview. No live SMS is sent, no real pupil/guardian data is used, and Cloud Functions remain emulator-only under the Spark/NGN 0 budget.
