01 · The problem

The gap is not ambition.
It is the hand-off.

Teachers are doing the work. Parents want to be involved. The tools between them often assume reliable internet, a computer lab or a smartphone in every home.

01

Planning time disappears

Lesson preparation competes with marking, attendance and a full classroom. Practical, curriculum-aligned planning support is hard to reach offline.

02

Attendance becomes admin

Paper registers are familiar, but following up on absences and keeping a reliable record takes time the teacher does not have.

03

Parents are far away

Many guardians use basic phones, have limited data or work away from home. An app-only parent channel would exclude the people it is meant to reach.

04

The network is not a guarantee

Connectivity can disappear mid-register. A useful classroom tool must keep working locally and make sync state honest.

02 · Our approach

Small enough to fit.
Serious enough to matter.

Tiny is built around three practical ideas: keep the teacher’s core work local, meet parents on SMS, and never let AI or connectivity gate the classroom.

⌂

Local-first by default

Room plus SQLCipher is the teacher’s source of truth. Lessons, attendance, pupil records and queued work remain usable offline. Nothing is labelled “synced” before a server acknowledges it.

✉

SMS is the parent bridge

No parent app. No parent login. A shared Tiny keyword and school code route parent messages, while absence alerts and weekly digests stay short, plain and localised.

✓

The teacher stays in charge

Progress is teacher-recorded instructional feedback, not AI grading. AI may draft a suggestion, but a teacher reviews and approves anything that reaches a parent.

03 · For teachers

A calmer classroom
workflow.

The app is designed for quick, thumb-friendly use on an existing Android phone — with clearly labelled preview functionality until each flow is verified.

Planned MVP▤

Offline attendance

Mark every active pupil present, absent or late. Save locally, submit explicitly and see pending sync honestly. Present and late never trigger an immediate parent SMS.

Preview shell✦

5E lesson planning

Engage, Explore, Explain, Elaborate, Evaluate. Save and revisit a practical lesson scaffold without a network connection.

Planned MVP◌

Pupil progress

Record a short subject-level observation, an indicator and an optional home activity. Edit after approval creates a new revision.

Planned MVP◎

Multiple classes

One teacher can manage several classes and subjects, with class-scoped access and a workspace switcher for multiple memberships.

Planned MVP↺

Durable sync

Domain changes and outbox commands are written atomically. Retryable failures back off; permanent failures surface as needs attention.

Optional, device-gated✧

Hybrid AI, never a gate

Short English on-device suggestions where supported, cloud assistance for richer or multilingual drafts, and a curated offline fallback. No pupil PII in prompts.

04 · For parents

One ordinary phone.
A clearer view.

Parents do not install Tiny. They receive short SMS updates and can reply from the handset they already use. Conversations are asynchronous, not live chat.

Absence only

Immediate absence alerts

After a submitted register is accepted, Tiny creates an alert only for absent pupils and eligible guardians. A shared phone endpoint is deduplicated.

Weekly

Approved digest

Attendance and teacher-approved progress in a short weekly message. Missing data is never presented as poor performance.

Two-way

Parent-initiated SMS

Parents can explain an absence or ask a question using the Tiny keyword and school code. Ambiguous senders receive no child-specific information.

Consent

Verified, opted-in contacts

A one-time in-person code proves possession of the handset and records opt-in. The school still verifies the guardian relationship through its normal process.

05 · How it works

From roll call to
a useful conversation.

  1. 01

    Set up once

    A teacher signs in, creates or joins a workspace and downloads the small set of class and lesson data needed offline.

  2. 02

    Teach without a signal

    Open a saved 5E plan, mark the register and record a short observation. Every save is local and durable.

  3. 03

    Sync honestly

    When connectivity returns, queued commands are retried with idempotency keys. The UI distinguishes pending, synced, conflict and needs attention.

  4. 04

    Reach the right guardian

    Only verified, consented endpoints receive child-specific messages. One endpoint can serve siblings without leaking unrelated records.

  5. 05

    Close the loop

    A parent reply reaches the authorised teacher inbox. The teacher responds from Tiny without exposing a personal number.

06 · Built for the real world

Offline-first is a
design constraint.

Low requirements are the product, not a downgrade. The Android app is designed for Android 8.0+ and inexpensive phones, with a small package, modest storage and no mandatory media downloads.

Offline

Useful without a signal

Local lesson plans, attendance drafts, pupil records and queued work remain available after the first authenticated sync.

Low bandwidth

Small, deliberate data

No mandatory video or image downloads. Sync batches are bounded. Background sync respects a Wi-Fi-only preference.

Multilingual

Language is a choice

Teacher UI: English, Hausa, Yoruba and Igbo. Parent SMS: those four plus Nigerian Pidgin, with human-reviewed templates.

10 · Questions

Plain answers,
including the limits.

Do parents need a smartphone or an app?

No. Parents use ordinary SMS. They do not create a Tiny account, install an app or log in. A parent-initiated message uses the Tiny keyword and school code for routing.

What happens when the teacher has no internet?

Core classroom work remains local. Attendance and progress are saved on the phone, and the UI shows pending sync. Parent notifications are not created until a server accepts the relevant command.

Does Tiny use AI to grade pupils?

No. Progress indicators are teacher-authored instructional feedback. AI may help draft generic teaching material or rephrase a de-identified note, but it cannot create or send parent-facing progress content without teacher review.

Is the on-device AI available on every Android phone?

No. On-device Gemini Nano is limited to specific supported devices. The core app does not depend on it. Cloud AI requires connectivity and the free-tier configuration; offline fallback is a curated resource.

Is Tiny collecting real pupil data in this demo?

No. This preview uses deterministic synthetic names and test phone numbers. Real pupil and guardian data are prohibited in development and demos.

Can a parent’s phone be linked to more than one child?

Yes, within a workspace one contact endpoint can be linked to multiple pupils, and a pupil can have multiple guardians. The phone endpoint is stored once to prevent duplicate sends. Shared handsets are treated as one contact endpoint.

Is production SMS live?

No. The current development mode is a deterministic mock adapter, with zero SMS budget. eSMS sandbox or production access requires separate authorization, provider setup and cost controls.

What is still missing before a real-school pilot?

A non-production Firebase project and access, App Distribution tester access, a supported on-device AI device for that specific acceptance gate, native-language review, legal/DPIA approval, a privacy notice, retention decisions, provider KYC and an approved production budget.
